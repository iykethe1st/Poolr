## Overview
Amends the Elite tier perk defined in ticket #43 (Trust score system). The original perk stated "zero platform fees on one group per month". With the updated contribution-based fee model, this is now correctly framed as "zero contribution fees for one group per month" - meaning Poolr waives the per-contribution platform fee for all contributions made within one nominated group per month for Elite users.

## What changed from ticket #43

### Original Elite perk
> 80-100 (Elite): Unlimited group size, zero platform fees on one group per month, priority payout scheduling

### Updated Elite perk
> 80-100 (Elite): Unlimited group size, zero contribution fees for one group per month (Poolr covers the fee for every contribution the Elite user makes in their nominated group that month), priority payout scheduling

## Implementation detail

### How the perk works
- An Elite user nominates one group per month where the fee waiver applies
- For every contribution the Elite user makes in that nominated group during the calendar month, `FeeService.collectFee()` sets `fee_amount = 0` for that contribution
- Poolr absorbs the cost - no reserve deposit for waived fees
- The user can change their nominated group once per month
- The perk applies only to the Elite user's own contributions - not to other members of the same group

### Schema changes
- [ ] Add `FeeWaiver` table:
```
FeeWaiver {
  id           uuid PK
  user_id      uuid FK -> User
  group_id     uuid FK -> Group
  month        date              -- first day of the calendar month this waiver applies to
  created_at   timestamp
  UNIQUE(user_id, month)         -- one waiver per user per month
}
```

### FeeService update
- [ ] Update `FeeService.calculateFee(contributionAmountKobo, userId, groupId, month)` to check for an active `FeeWaiver` for this user/group/month combination
- [ ] If a waiver exists: return `fee_amount = 0`, skip reserve deposit, create `ContributionFee` with `fee_amount = 0` (for audit trail)
- [ ] If no waiver: standard fee tier calculation unchanged

### New endpoints
- [ ] `POST /users/me/fee-waiver` -- Elite user nominates a group for fee waiver for the current month. Body: `{ group_id }`. Returns 403 if user is not Elite tier. Returns 400 if waiver already set for this month.
- [ ] `GET /users/me/fee-waiver` -- returns the current month's nominated group and fee waiver status

### Trust score integration
- [ ] In `TrustScoreService`, when a user crosses into Elite tier (score >= 80), send a push + in-app notification: "You have reached Elite status. Nominate a group to enjoy zero contribution fees this month."

## Tests
- [ ] `calculateFee()` returns 0 for Elite user with active waiver for the correct group and month
- [ ] `calculateFee()` returns normal fee for Elite user whose waiver is for a different group
- [ ] `calculateFee()` returns normal fee for Elite user after their waiver month has passed
- [ ] `POST /users/me/fee-waiver` returns 403 for non-Elite users
- [ ] `POST /users/me/fee-waiver` returns 400 on second call for the same month

## Acceptance criteria
- Elite user pays zero platform fee on all contributions in their nominated group for the nominated month
- Non-Elite users are never granted fee waivers
- A waived contribution creates a `ContributionFee` record with `fee_amount = 0` for audit trail
- Reserve is NOT funded from waived fees (Poolr absorbs the cost)
- User can update their nominated group once per month but cannot change it twice
- Fee waiver expires automatically at month end with no manual intervention
