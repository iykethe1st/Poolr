## Overview
Small amendment to ticket #44 (B2B cooperative and corporate group onboarding). The `Organisation.billing_type` enum used `TRANSACTION_FEE` to describe the standard per-transaction fee model. With the revised fee structure charging on contributions (not transactions broadly), this enum value is renamed to `CONTRIBUTION_FEE` for accuracy and clarity.

## What changed from ticket #44

### Original schema
```
Organisation {
  billing_type  enum  -- TRANSACTION_FEE | FLAT_MONTHLY
}
```

### Updated schema
```
Organisation {
  billing_type  enum  -- CONTRIBUTION_FEE | FLAT_MONTHLY
}
```

## Enum definition update
```
enum OrgBillingType {
  CONTRIBUTION_FEE  -- standard Poolr flat fee per contribution (fee tiers from FeeService)
  FLAT_MONTHLY      -- negotiated flat monthly rate for the organisation, no per-contribution fee
}
```

## Behaviour clarification

### CONTRIBUTION_FEE orgs
- Standard fee tier applies to every contribution made by a member of an organisation-owned group
- Fee calculated by `FeeService.calculateFee()` exactly as for non-organisation groups
- No special treatment - this is the default

### FLAT_MONTHLY orgs
- Organisation pays a negotiated flat monthly fee (stored in `Organisation.monthly_fee`)
- Per-contribution fee is waived for all members of all groups under this organisation
- `FeeService.calculateFee()` returns 0 for contributions in FLAT_MONTHLY organisation groups
- Poolr invoices the organisation directly for `monthly_fee` at the start of each month
- A new `OrgInvoice` table tracks monthly invoices and payment status

## Schema changes

### Update `Organisation` model (from ticket #44)
- Rename `billing_type` enum value `TRANSACTION_FEE` to `CONTRIBUTION_FEE`
- Add `monthly_fee` (int, nullable) -- monthly flat fee in kobo; required when billing_type = FLAT_MONTHLY

### New `OrgInvoice` table (FLAT_MONTHLY orgs only)
```
OrgInvoice {
  id              uuid PK
  organisation_id uuid FK -> Organisation
  month           date          -- first day of the billed month
  amount          int           -- monthly_fee in kobo
  status          InvoiceStatus -- PENDING | PAID | OVERDUE
  paystack_ref    string?       -- set when paid
  issued_at       timestamp
  paid_at         timestamp?
}

enum InvoiceStatus { PENDING PAID OVERDUE }
```
